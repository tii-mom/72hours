# 72hours Green Book

Last updated: 2026-04-28

## 摘要

72H 不是一个只让人看价格、等消息的代币。

72H 要讲的不是一根 K 线，而是一条普通人走进加密世界的路。

这条路从真实产品开始，穿过 900 亿玩法池和 72 小时赛季，进入“通往财富自由之路”的战队、邀请和排行榜，最后把一部分普通用户带到建设者的位置。

这一次最重要的变化是：72H 不只讲故事。它把固定总量、`90,000,000,000 72H` 玩法池、有效存入和锁定、战队协作、邀请传播、线上线下学习放在同一条路径上。

72hours 面向的是加密圈里的普通人：会买币、会进社群、会看项目，但还没有真正参与过加密应用开发的人。

72H 的故事很简单：

- 用起来：进入真实产品和服务
- 玩进去：在“通往财富自由之路”完成有效存入并锁定，进入 72 小时赛季、战队、邀请和排行榜
- 学会建造：通过 AI 辅助开发学习，从用户走向加密应用建设者

72H 已在 TON 链上固定发行，总量是 `100,000,000,000 72H`。核心点只有一个：总量固定，不能再增发。

`90,000,000,000 72H` 是 72 小时赛季玩法池。它让故事有重量，也让普通用户看见一个明确目标：通过真实参与，按公开规则争取领取资格。没有达标或没有通过核对，就不能把它当成已经可以领取的奖励。

本文不构成投资建议，也不承诺收益。它只说明 72H 可以怎么用、怎么玩、怎么学，以及哪些边界必须说清楚。

## 1. 72H 的代币经济为什么不一样

很多代币只讲“未来会有价值”。72H 更想回答一个普通用户真正关心的问题：我现在能做什么，我能进入哪里，我能不能从只会看项目的人，变成能参与、能判断、甚至能建设的人。

72H 的设计重点不是投票，也不是复杂金融术语，而是把代币放进真实动作里：

- 用 72H 进入产品和服务
- 用 72H 参与生态应用
- 用 72H 进入 72 小时玩法
- 用 72H 在“通往财富自由之路”里完成有效存入并锁定，进入真实赛季计算
- 用 72H 报名学习和开发训练

72H 的总量固定为 `100,000,000,000 72H`，主要分成几类用途：

- `90,000,000,000 72H`：赛季玩法池，用于 72 小时赛季玩法，按公开规则进入领取池或锁定池
- `4,500,000,000 72H`：预售池
- `4,500,000,000 72H`：生态池，用于生态应用和后续激励
- `500,000,000 72H`：开发基金，用于产品、学习和建设支持
- `300,000,000 72H`：团队释放
- `200,000,000 72H`：早期用户和运营

这套模型的重点不是把分配表写得复杂，而是让每一部分供应都有明确用途。72H 要把“持有代币”变成一连串真实动作：进入产品、有效存入、加入赛季、形成战队、学习构建。

## 2. 72H 的玩法为什么不一样

72H 不希望用户只读一段叙事，然后等待价格变化。72H 希望用户能进入一个看得见的系统。

### 2.1 90B 赛季玩法池

`90,000,000,000 72H` 被放进赛季玩法池，用于 72 小时赛季。

这不是为了制造一个漂亮数字，而是为了让用户感到：这里不是只有口号，这里真的有一套围绕时间、行动、团队和规则展开的玩法。

这个玩法可以简单理解为：

- 一轮是 `4` 小时
- 一季有 `18` 轮
- 最多 `10` 个赛季
- 每轮有固定的 `500,000,000 72H` 玩法库存

如果一轮达成公开规则，这部分会进入用户领取池。符合条件的用户之后可以按公开名单领取。

如果一轮没有达成规则，这部分不会进入管理员钱包，而是进入锁定池，按公开条件等待后续处理。

这套设计想解决一个问题：玩法可以热闹，但资金路径必须说清楚。用户看到的是 900 亿玩法池，但真正能不能领取，要看公开规则、链上记录、名单证明和平台核对。

### 2.2 有效存入、战队和排行榜

普通用户不需要一开始就理解所有技术细节。你可以先做几件简单的事：

- 领取 72 小时入场卡
- 加入一个战队
- 邀请朋友
- 查看排行榜
- 生成自己的身份卡并分享
- 如果想进入真实赛季计算，完成有效存入并锁定

这里有一个重要边界：热度只是热度，不等于真实代币奖励。

真实奖励资格要看公开规则、链上记录、名单证明和平台核对。这样既能让社区传播起来，也能避免把普通分享或一次存入包装成收益承诺。

“通往财富自由之路”的重点不是“存了就发财”。这个名字表达的是方向和愿景，不是结果承诺。它真正要做的，是把围观变成行动：用户用链上存入和锁定证明自己真的参与，再通过战队、邀请和排行榜进入 72 小时赛季。

### 2.3 从“看项目”到“进入项目”

很多项目只让用户看故事。72H 希望用户进入具体场景：

- 在 WAN 里使用 72H
- 在 Season War 里参与 72 小时玩法
- 在“通往财富自由之路”里完成有效存入并锁定，理解战队、邀请和排行榜
- 在应用席位机制里理解阶段、名额、风险和验证

用户不是靠听别人解释来理解 72H，而是在一次次使用和参与中慢慢形成判断。真正的信任，不是写在海报上的，是用户亲手连接钱包、加入战队、看到规则、理解流程之后长出来的。

## 3. 普通人如何通过 72H 学习成为开发者

72H 的长期目标不是只让用户买入和等待，而是让一部分普通用户学会构建。

加密行业最大的门槛，往往不是一串技术名词，而是普通人不知道自己从哪里开始。72H 要把这个入口拆小：先看懂钱包，再看懂页面，再看懂规则，最后看懂一个应用为什么能跑起来。

通过线上和线下的 AI 辅助开发学习，普通用户可以学习：

- 钱包怎么连接
- TON 链上的应用怎么交互
- 一个前端页面如何展示状态
- 入场卡、战队、排行榜、分享卡怎么设计
- 公开名单、领取资格、平台核对为什么重要
- 如何用 AI 工具和模板做出自己的加密应用原型

这不是把课程包装成项目，也不是让所有人一夜之间变成高手。

更实际的路径是：

```text
普通用户 -> 参与者 -> 贡献者 -> 应用建设者
```

先使用，再参与，再拆解，最后尝试自己做。72H 的野心不是培养旁观者，而是让一部分普通用户长出建设者的手感。

## 4. 72hours 如何形成真实需求

72hours 的需求来自五件事：

- 用户使用产品和服务
- 用户在“通往财富自由之路”里完成有效存入和锁定
- 应用在生态里上线和成长
- 72 小时玩法、900 亿玩法池、战队和排行榜带来持续参与
- 线上和线下学习带来新的建设者
- 社区、合作伙伴和分发渠道带来更多用户

72H 不应该只依赖一句口号。它需要让用户真的有地方可去，有事可做，有东西可学。一个普通用户来到 72H，不应该只问“什么时候涨”，而应该能问出新的问题：“我可以加入哪一轮？我属于哪个战队？我能不能学会自己做一个应用？”

## 5. 必须说清楚的边界

- 72H 不是治理权
- 参与生态不等于一定有奖励
- 存入并锁定不等于保证收益
- 900 亿是玩法池，不是每个参与者都保证可以领取
- “通往财富自由之路”是产品愿景名称，不是财富自由承诺
- 任何奖励都不能提前承诺
- 玩法规则可能随着阶段更新
- 链上操作需要用户自己支付网络手续费
- 领取资格需要公开规则、链上记录和平台核对
- 本文不构成投资建议、法律建议或收益承诺

## 6. 目标

72H 要做的不是让普通用户只“持有”。

72H 要让用户完成三步：

- 用起来：进入真实产品和服务
- 玩进去：完成有效存入并锁定，进入 72 小时玩法和社区协作
- 学会建造：通过线上和线下学习，理解并尝试开发加密应用

一句话：72H 是普通人进入加密应用世界的入口。先用起来，再用真实动作参与，最后学会自己建造。
